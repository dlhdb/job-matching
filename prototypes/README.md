# 介面原型

用假資料確認介面是否符合需求的原型，確認後才修改產品文件與實作。

- 資料都是虛構的，不讀職缺資料庫，也不寫入任何東西。
- 不代表實作使用的技術：原型是單一 HTML 檔加原生 JavaScript，正式實作的技術選型另外決定。

## 開啟方式

```bash
python3 -m http.server 8000 --directory prototypes/job-table
```

VS Code 會自動轉發 port，在本機瀏覽器開 `http://localhost:8000`。用 http 開啟，瀏覽器才會記住選好的欄位與篩選。

## 原型

- `job-table/`：職缺表、抓取、設定三個分頁。選欄位、篩選、排序、展開一列看完整內容，抓取後預覽再存入，勾選職缺送去評分，以及設定的版本、套用與試跑清單。頁首的「顯示功能歸屬」會標出每個欄位、篩選與區塊屬於哪個功能。
