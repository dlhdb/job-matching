## 產品概念
求職雷達，過濾出符合自我發展方向的職缺
    
## 解決問題
避免花大量精力在海量求職平台中人工過濾職缺。
了解現在不同產業、公司的發展方向

## 核心技術
- **工作評分邏輯**：設計工作評分方法與提示詞。
- **從不同求職平台中獲取職缺資訊**：從網路上截取職缺資訊，轉換成結構化的資訊，以利後續讓 ai 分析。
- **擷取公司的相關資訊與評價**：從網路上截取公司相關資訊，轉換成結構化資訊，以利後續讓 ai 分析。
- **設計工作流讓 ai 分析職缺與公司**：依據工作評分邏輯給工作打分，並給出簡短評語
- **分析工作趨勢與興趣分佈**：從全台、全球角度來分析職缺趨勢，並發現自己對職缺或產業的興趣分佈

## 使用聲明
本專案僅供個人學習與研究使用：
- 爬蟲程式已限制請求頻率，避免對目標網站造成負擔。
- 抓取到的職缺資料只存在本機（`output/` 已排除於版本控制），不會公開或轉散布。
- 職缺與公司資訊的著作權屬於原網站及刊登者。使用前請自行確認並遵守各平台的服務條款。
