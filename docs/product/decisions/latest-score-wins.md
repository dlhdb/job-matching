# 多筆評分以最新的一筆為準

## 決策背景與問題

同一筆職缺可以有多筆評分紀錄：自動評分每次重評都新增一筆，手動評分也每次新增一筆（見 [job-auto-scoring §8](../features/job-auto-scoring.md#8-追蹤同一筆職缺的評分變化history)）。依分數列出、取出單筆時，每筆職缺只能用一筆代表的評分，問題是要用哪一筆。

## 考慮過的替代方案

- 有手動評分時用手動評分，沒有時才用最新的自動評分：
  - 這是原本採用的做法，不再採用。
  - 查詢多一層判斷。使用者手動評分之後又用 `--job-no` 重評，查詢仍然看到舊的手動評分，看不出重評的結果。
  - 保護手動評分的目的，改由選職缺的規則達成：不指定 `--job-no` 時只評沒有任何評分的職缺（見 [job-auto-scoring §4.2.12](../features/job-auto-scoring.md#4212-要評哪些職缺)），整批評分不會蓋過手動評分。

## 最終決策

- 用評分時間最新的一筆，不分自動或手動；評分時間相同時，用後寫入的一筆。
- 手動評分只會在使用者自己用 `--job-no` 重評時被蓋過，舊的紀錄仍然保留，可以取出所有評分紀錄比較。
- 詳細規則見 [job-auto-scoring §8.2.3](../features/job-auto-scoring.md#823-代表的評分)。
